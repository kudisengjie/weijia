## 实施顺序

1. 测试先行：独立执行器的五路上限、去重、暂停隔离、旧会话响应、STEP_CLAIMED 与失败停止；草稿模型字段和资料恢复。
2. 复用现有上传解析组件，增加部分草稿读取/恢复、读取中禁止切换、修改事件。保存选中的工作表和完整公司正文，不保存 File 对象或浏览器明文持久缓存。
3. 工作区工具栏及五页签；新建、自动/手动保存、切换前保存、版本冲突保留本页修改并提供明确重新读取。运行后锁定各自资料和模型。
4. runtime 以 Map 隔离每个批次执行器和返回结果；其他任务返回不能切换当前页面。总览同时展示草稿与历史。认证失效清空全部私有前端状态。
5. 真实 Edge + 本机 FastAPI + 隔离 PG 联调五工作区、切换/刷新、独立暂停继续、一个失败不影响其他输出、第六个拒绝、下载归属和权限；只替换付费上游。
6. 构建、受影响认证回归、桌面/手机截图查看、内联审查；更新恢复入口与检查点并本地提交。记录未上线与 Worker 待办。

## 验收约束

- 不靠内存计数绕过后端五名额；草稿/暂停/失败仍占名额，完成/取消释放。
- 保存失败/冲突不得悄悄切换并丢资料；输入发生在保存途中不得被旧响应覆盖。
- 每个工作区模型仅选本人已配置厂商；启动后展示服务器固定快照。
- 每批次仅一个浏览器循环；STEP_CLAIMED 只读取，不重复提交已认领的步骤；退出或换账号后旧循环不得恢复。
- 真实模型及生产部署未测时明确说明，不能用固定响应冒充。
