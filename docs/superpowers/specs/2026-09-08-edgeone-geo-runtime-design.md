# EdgeOne 零雪 GEO 可运行版

已确认：EdgeOne Pages 部署、固定账号登录、用户自带八家模型 API、所有批次共用站主 IMA、站主可随时更新月度凭据、登录页采用 A 方案。

## 边界与结构

- 官网仓库 `geo-site` 升级为同域前端与 Node.js Cloud Functions。主站其他页面不改动。本地 Python 工作台作为业务流程参考，保留原程序。
- `cloud-functions/api/[[path]].js` 为唯一 API 入口；私有模块位于 `server`，构建只向 `dist` 复制公开资源和函数包，不发布源码目录、测试、环境变量或本地数据。
- 复用现有八家厂商、十六个具体模型名称与图标。模型默认端点使用官方地址；按提供商保存 Key，支持设置该账户实际可调用的模型 ID。单批次创建时锁定提供商、模型 ID，不降级、不隐式切换。
- 不自动读取/使用站主 Windows 中的模型 Key。网页用户必须填写自己的模型 Key。

## 认证与凭据

- 账号由服务端环境变量提供，密码使用 scrypt 加盐哈希，明文密码不进入 Git。安全 Cookie 会话、CSRF 校验、同源检查、登录频率限制覆盖所有私有 API。
- 单个已授权账号，不开放注册；每个浏览器登录会话独立隔离模型配置和批次，避免共享账号使用者互相覆盖 Key。会话到期后重新配置；不承诺跨设备共享个人模型 Key。
- 模型 Key 与共享 IMA Key 使用 AES-256-GCM 加密后放入 Blob。服务端根密钥只在环境变量。前端只收到配置状态、更新时间与用户填写的模型 ID。
- IMA 初始凭据读取服务端 `IMA_OPENAPI_CLIENTID` / `IMA_OPENAPI_APIKEY`，本地开发可以从已配置的 Windows 环境变量获取。后续覆盖值来自加密 Blob，强一致读取，更新后下一请求生效。
- IMA 更新入口必须同时校验登录会话、CSRF 和独立管理员更新口令。只修改共享 IMA，不向普通用户回显凭据；新凭据完成一次真实连接验证并确认可访问固定 `copilot` 后才替换。失败保留旧值。有效期日期由管理员填写，页面显示到期提示，不擅自续期。
- 设置页提供 IMA 状态及管理员更新折叠面板；不开放 IMA Base URL，防止凭据发送到其他地址。

## 批次流程

- 上传任务表并逐品牌绑定公司文档，浏览器解析全部文字，展示可截断的预览；提交给后端的原文不可被预览截断。服务端复核字段、品牌、篇数、大小和模型配置。
- 读取固定 copilot 目录下生成规则、审核规则、最新记忆文档，并按任务问句、平台和备注检索指定 GEO 知识库；每一步读取进度持久化。缺失、重复或不可解析原文明确阻止生成，不用摘要替代原文。
- 分阶段执行：准备资料 → 生成 → 严格审核 → 必要时修订一次 → 再审核 → 最终 Markdown。每个函数调用只执行一个有界阶段；普通模型调用设置低于 120 秒的超时。
- 客户端顺序驱动批次，已完成阶段保存后不会再次生成。关闭页面停止提交后续阶段，回到历史批次可以明确继续。此版本不承诺关闭页面仍无限后台执行。
- Blob 使用强一致读取与条件写入实现步骤领取，拒绝重复/并发请求；超时或不确定结果不自动重发模型请求，用户明确重试后才恢复。
- IMA 过期显示可行动错误；轮换凭据不改变已经锁定的规则与已完成文章，也不从头重复已完成任务。

## 登录页 A

桌面端宽卡片左右分栏，左侧展示用户提供的透明人物，右侧为手机号、密码与登录按钮。移动端单栏，人物区域压缩到约 130–160px，使用 contain 保持比例、保留完整人物，输入框字号至少 16px、按钮至少 44px。采用现有冰蓝、深蓝字色，键盘焦点清楚。原始素材已确认 1024×1024 且带透明通道。

## 验收

覆盖未登录拒绝、密码错误与限流、CSRF、凭据不回显、普通用户不能轮换 IMA、轮换失败保留旧凭据、重启后读取新凭据、批次模型锁定、阶段重复请求、失败无自动重试、仅审核通过可下载。真实 IMA 测试只验证一次配置与规则入口；模型真实测试只使用用户主动配置且明确测试的提供商。构建后检查发布目录无密钥，浏览器验收桌面和手机登录布局及主要表单。

## 部署前提

需在 EdgeOne 项目中设置环境变量、启用函数与 Blob，并将根目录设为 `geo-site`、构建命令 `npm run build`、输出 `dist`。GitHub 推送不等于这些控制台设置已完成；无法访问控制台时交付可部署代码与精确配置步骤，明确线上状态。
