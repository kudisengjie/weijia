# `geo.lxue.xin` 静态零雪 GEO 工作台设计

## 目标

为 `https://geo.lxue.xin/` 提供一个与本地零雪 GEO 程序认知结构一致的独立静态页面。页面可以在浏览器本地读取并预览任务表和公司介绍文档，但不能创建任务、连接 IMA、连接 DeepSeek、保存历史或消耗 API 额度。

## 部署边界

- 源码位于官网仓库的 `geo-site/`，但作为独立 EdgeOne Pages 项目发布。
- EdgeOne 项目根目录设为 `geo-site`，生产分支为 `master`，最终绑定 `geo.lxue.xin`。
- 官网页脚继续使用完整地址 `https://geo.lxue.xin/`，不使用本地 IP，也不依赖官网内部 `/geo` 路由。
- `geo-site/edgeone.json` 禁止网络连接：`connect-src 'none'`。

## 页面结构

- 顶部：返回官网、文件预览工作台、本地读取状态。
- 左侧：上传资料、任务校验、生成审核、文章输出四步流程，以及批次、历史、已完成、设置视图。
- 主区：Excel 任务表上传与内容表格预览；公司文档多选与正文预览；静态前置检查。
- 右侧：完整零雪形象 IP、本地读取数量和零 API 请求状态。
- 操作区：“开始生成”永久禁用，并明确说明当前页面只读取文件。

## 文件读取能力

- XLSX/XLS/CSV：读取工作表、总行数、最多列数，展示前 20 行和 12 列。
- DOCX：提取正文纯文本。
- PDF：提取文字型 PDF 的页面文本；扫描图片 PDF 会给出提示。
- TXT/MD/RTF：读取并显示纯文本；RTF 只做基础控制符清理。
- ODT：从 `content.xml` 提取段落文字。
- 旧 DOC：允许选择，但明确提示先另存为 DOCX，避免伪装成成功读取。

## 安全与隐私

- 文件只进入当前浏览器内存，不上传、不持久化；刷新或关闭页面即清空。
- 文档内容只通过 `textContent` 写入 DOM，禁止把文档内容作为 HTML 执行。
- 页面不包含任何 IMA、DeepSeek、数据库或登录凭据。
- 所有解析库和 PDF Worker 随站点本地发布，不依赖第三方 CDN。
- 单文件上限 25 MB，表格和正文均限制页面展示量，降低浏览器冻结风险。

## 验收标准

- 静态验证确认独立目录、解析代码、禁用运行按钮、安全头和最终域名入口完整存在。
- 使用官方 Google Chrome 真实选择用户提供的 Excel，能够显示工作表和单元格内容。
- 使用官方 Google Chrome 真实选择 DOCX，能够显示提取后的正文和字符数。
- Chrome 控制台无错误，资源请求只指向当前站点，不出现 IMA 或 DeepSeek 请求。
- 桌面与窄屏均无页面级水平溢出，文件内容区域允许自身滚动。
