# 官网静态 GEO 模型切换设计

## 目标

官网 `geo-site` 继续作为纯静态文件预览页面，同时允许访客在 Agnes 2.5 Flash 与 DeepSeek V4 Flash 之间切换展示状态。真实 Agnes 调用只存在于本地 `Lxue-GEO` 程序，官网不得具备生成或 API 调用能力。

## 范围与边界

- 官网默认展示 Agnes 2.5 Flash，可切换为 DeepSeek V4 Flash。
- 当前选择只存在于页面内存，刷新页面后恢复默认 Agnes。
- 工作区模型卡、状态舱和设置页同步展示当前选择。
- “开始生成”按钮始终禁用，API 请求计数始终为 0。
- 官网不增加 API Key 输入、连接测试、后端接口、服务端配置、浏览器存储或网络请求。
- 本地 `Lxue-GEO` 的 Agnes 真实接入保持不变；本设计不复制其运行逻辑到官网。

## 结构与数据流

`geo-site/src/app.js` 维护一个仅含当前模型标识的页面内存状态。设置页的原生选择控件更新该状态，再统一刷新工作区模型卡、状态舱和设置页说明。页面加载时使用 Agnes 作为初始值。

模型切换不进入文件解析、前置检查或运行流程。现有文件读取仍只发生在浏览器内存；运行按钮继续保持禁用，不注册生成处理程序。

## 交互与可访问性

- 设置页提供带明确标签的原生下拉选择框。
- 可选项固定为 Agnes 2.5 Flash 与 DeepSeek V4 Flash，不允许自由填写模型 ID。
- 连接状态统一显示“未连接”或“静态页未连接”，避免让用户误以为已配置。
- 页面静态提示明确说明：切换仅供展示，不会连接 IMA、Agnes 或 DeepSeek，也不会消耗额度。

## 错误处理与安全

由于没有外部请求和持久化，模型切换不产生网络错误或凭据错误。若脚本加载失败，HTML 中的默认 Agnes 展示仍成立，生成按钮仍然禁用。代码中不得出现真实密钥、供应商请求地址或 `fetch` 调用。

## 验证

只做一次针对性验证：

1. 构建静态资源成功。
2. 切换模型后，工作区、状态舱和设置页展示同步变化。
3. 刷新页面后恢复 Agnes 默认值。
4. 生成按钮始终禁用，页面不发起 API 请求。
5. 移动端布局不溢出，现有文件预览功能保持可用。
